# 📚 BookAI — LLM-powered Book Intelligence Platform

BookAI es un proyecto que utiliza modelos de lenguaje (LLM) y técnicas modernas de IA para analizar, recomendar y generar conocimiento a partir de una base de datos de libros. El objetivo es crear un ecosistema inteligente capaz de responder preguntas, detectar patrones y ofrecer recomendaciones personalizadas.

---

## 🚀 Características principales

- **Recomendador inteligente** basado en embeddings y razonamiento de LLM.
- **Chatbot literario** capaz de responder preguntas sobre libros, autores y tendencias.
- **Análisis automático** de patrones editoriales (precios, ratings, géneros, años).
- **Generación de contenido**: sinopsis, reseñas, títulos alternativos.
- **Búsqueda semántica** avanzada sobre todo el catálogo.
- **Dashboard interactivo** (opcional) para explorar datos con lenguaje natural.

---

## 🗂️ Estructura del dataset

El dataset contiene los siguientes campos:

| Campo            | Descripción |
|------------------|-------------|
| `Book name`      | Título del libro |
| `Author`         | Autor/a |
| `Rating`         | Valoración promedio |
| `Reviews count`  | Número de reseñas |
| `Form`           | Formato (tapa dura, kindle, etc.) |
| `Price`          | Precio |
| `Reading age`    | Edad recomendada |
| `Print Length`   | Número de páginas |
| `Publishing date`| Fecha de publicación |
| `Genre`          | Género literario |
| `id_2023` `id_2024` `id_2025` | Identificadores por año |
